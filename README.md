# Cursor AI Tools Setup

## Overview

This repository documents my setup process for Cursor IDE, Claude Code, Codex, and GitHub.

The purpose of this task was to install the required tools, test the basic workflow, document the steps clearly, and push the documentation to a public GitHub repository.

## Tools Installed / Used

- Cursor IDE
- GitHub
- Git
- Claude Code add-on / extension in Cursor
- Codex add-on / extension in Cursor

## Steps Completed

1. Installed Cursor IDE on Windows.
2. Opened Cursor and verified that the application was installed successfully.
3. Opened the Extensions panel inside Cursor.
4. Searched for the Claude Code add-on / extension.
5. Searched for the Codex add-on / extension.
6. Created a public GitHub repository for this setup task.
7. Opened the repository inside Cursor.
8. Created this `README.md` file.
9. Documented the tools installed, steps completed, and issues encountered.
10. Committed the README file using Git.
11. Pushed the repository to GitHub.

## Issues I Ran Into

During the setup process, Cursor displayed an **“Update required”** message saying:

> This version of Cursor is no longer supported. Please update to continue.

This appeared even after I had downloaded and installed the latest available Cursor version.

I also checked the installed Cursor version from the application details:

- Cursor Version: 2.5.26
- Setup Type: User setup
- VSCode Version: 1.105.1
- OS: Windows x64

## How I Tried to Solve It

I approached the issue step by step:

1. Clicked the restart/update option inside Cursor.
2. Reopened Cursor after the update prompt.
3. Verified the installed Cursor version.
4. Continued working inside the repository because the editor was still usable.
5. Documented the issue clearly instead of ignoring it.
6. Completed the README file and proceeded with the Git commit and push workflow.
